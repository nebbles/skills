Six Rules for Clear Writing (based on Orwell's Politics and the English Language)

1. Never use a metaphor, simile, or other figure of speech which you are used to seeing in print, or that is overused. (Project-specific language where it has been pre-defined in a glossary or context file is acceptable.)
2. Never use a long word where a short one will do.
3. Cut out any word you do not need.
4. Use active voice instead of passive voice.
5. Use everyday English words instead of foreign or technical jargon (unless required for accuracy of technical explanation, or pre-defined project-specific language).
6. Break these rules before writing anything totally silly or unhelpful.

If it helps, or if the user is struggling to understand by asking for simplicity, consider using ASD-STE100 Simplified Technical English in your reporting style.
